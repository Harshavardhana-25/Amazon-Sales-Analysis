# Title : Amazon Sales Performance Analysis

## Project Overview

This project analyzes Amazon sales data to understand business performance and sales trends.

## Tools Used

* Python (Pandas)
* Power BI

## Data Description

The dataset contains order date, sales, profit, category, and region details.

## Data Preparation

Performed data validation such as checking missing values, duplicates, and outliers.

## Dashboard

Created a two-page Power BI dashboard:

* Overview page with KPIs and trends
* Detailed page with category and region analysis

## Key Insights

* Electronics category performed best
* Sales trends change over time
* Some regions have lower profit
